My Portfolio

🚀 About the Project

This is my personal portfolio website, built using Next.js and Tailwind CSS, and hosted on Vercel. It showcases my skills, projects, and experiences as a developer.

🌟 Features

Responsive Design - Fully optimized for mobile and desktop devices

Projects Showcase - A display of my best work with links to repositories

About Me - Insights into my background, skills, and interests

Contact Form - Easily get in touch with me

🛠️ Technologies Used

Framework: Next.js

Styling: Tailwind CSS

Deployment: Vercel

UI Components: ShadCN
